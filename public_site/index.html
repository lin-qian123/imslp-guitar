METHOD / 02

整理不是堆放
Method before volume

—

每个数字背后，都有明确的分类、身份与来源。

Every record has a reason to be here.
  1. 01

    精确编制

    只使用获批准的 IMSLP 分类；改编谱还必须匹配明确的目标编制分区。

    Allowlisted, anchored instrumentation
  2. 02

    原作与改编分离

    原作分类和 (arr) 分类独立保存，避免混淆作品身份。

    Originals and arrangements stay distinct
  3. 03

    按作品去重

    同一作品可以属于多个编制分类，但在检索结果中只出现一次。

    One work, many memberships
  4. 04

    可追溯双语

    英文原名始终保留；中文名用于辅助检索，并按 IMSLP 作品编号锁定。

    Source titles preserved, translations reviewed

SOURCE NOTE / 03

本站是索引，不是 IMSLP 镜像

每条作品记录都直接指向 IMSLP 原页面。乐谱文件不在本站托管；版权状态与使用条件以 IMSLP 页面及文件所附许可为准。

This site is an independent index, not an IMSLP mirror. Score files are not hosted here; copyright status and reuse terms remain those shown by IMSLP and each file’s license.
