# IMSLP 吉他与室内乐总乐谱库

本项目以已经验证的三吉他改编谱库为基础，建立按 IMSLP 原始分类组织、可以通过 `file://` 离线浏览和搜索的吉他总乐谱库。现已同时覆盖纯吉他，以及吉他与弦乐、木管、铜管、键盘/自由簧、拨弦、打击乐和其他室内乐编制。

## 目标入口

```text
file:///Volumes/PHILIPS/programs/muse-cache/imslp/index.html
```

## 收录范围与分类

- 独奏吉他及 2、3、4、5、6、7、8、9、12、16 把吉他分类。
- 对应的原作和 `(arr)` 改编分类。
- 六至十弦吉他、Guitar Ensemble 和 Guitar Orchestra 等纯吉他分类。
- 吉他与小提琴、中提琴、大提琴、长笛、双簧管、单簧管、萨克斯管、圆号、小号、钢琴、管风琴、手风琴、口琴、曼陀铃、竖琴、打击乐等重奏分类。
- 含吉他的三重奏、四重奏及更丰富的混合室内乐编制。
- IMSLP 原作分类与 `(arr)` 改编分类分别保存，不合并名称或清单。
- 排除电吉他、贝斯吉他、夏威夷/钢弦/滑棒吉他、人声与合唱、电子/磁带、大型管弦乐，以及“吉他或其他独奏乐器”这类备选编制。

## 实际结构

- 根 `index.html`：总分类导航与跨分类搜索。
- IMSLP 原名目录：每个分类独立 HTML、Markdown、CSV 和 JSON 双语目录。
- 分类 `scores/`：按音乐家/作品/文件保存 PDF。
- 分类 `metadata/`：分类成员、清单、翻译、缓存和下载覆盖记录。
- `config/categories.json`：纯吉他分类；`config/mixed_categories.json`：吉他与其他乐器/室内乐分类。
- 根 `scripts/`：分类发现、元数据、下载、翻译、迁移、渲染和验证工具。

## 证据边界

所有活动 PDF 都按文件头、目标大小和 IMSLP SHA-1 严格校验。当前 65 条分类记录受 IMSLP 版权复核、交互验证或旧版本替换影响而暂不可取得（纯吉他 50 条、混合重奏 15 条），因此本库不能称为 100% 全量下载完成；目录和统计会明确区分有效文件与上游缺失记录。
