## IMSLP / Petrucci Music Library

This independent project organizes source-attributed records from the
[International Music Score Library Project](https://imslp.org/). It is not
affiliated with, sponsored by, or endorsed by IMSLP, Project Petrucci LLC, or
their mirror operators.

- IMSLP work and category pages are linked as the source of each public record.
- English titles, composer attributions, work IDs, and category names are
  preserved as source identity fields.
- The public website does not host score files.
- Copyright status differs by jurisdiction. Users must follow the status and
  license displayed on each IMSLP page and within each file.
